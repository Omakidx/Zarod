# followbot

A personal Telegram bot that follows X and Instagram accounts using your own session cookies, routed through a pinned Surfshark VPN. It runs on this machine via `./dc` (Docker Compose), with secrets in `.env.local`.

📚 **All the documentation is in [docs/](docs/README.md):**

- [docs/README.md](docs/README.md): overview
- [docs/tech-stack.md](docs/tech-stack.md): stack, architecture, and security model
- [docs/execution-phase.md](docs/execution-phase.md): the remaining steps to go live, and what you need to provide
- [docs/my-use-flow.md](docs/my-use-flow.md): how to use the bot day to day

> ⚠️ This breaks X's and Instagram's terms. Test on throwaway accounts first.
